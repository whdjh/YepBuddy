# 위젯 기능

> iOS WidgetKit 기반 잠금화면 / 홈화면 위젯. React Native 바깥의 Swift / SwiftUI 영역에서 구현한다.

## 개요
- 타입: iOS 위젯
- 구현: Widget Extension + SwiftUI
- 데이터: Widget Extension이 HealthKit 직접 조회
- 갱신: TimelineProvider + 앱에서 `WidgetCenter.reloadAllTimelines()`

## 핵심 규칙
- 앱과 위젯은 동일 App Group 사용
- 위젯은 월별 운동 유무만 표시
- 운동량 강도 차등 없이 on/off만 표현
- 위젯 탭 시 앱 메인화면으로 이동

## 개발 환경
- Xcode 16+
- `@bacons/apple-targets` 기반
- 필요 시 Expo prebuild / native 타겟 설정
