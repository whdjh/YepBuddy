# 프로틴 상세 기능

> 개별 제품의 상세 정보, 가격 추이, 외부 구매 링크를 보여주는 화면.

## 개요
- 진입: 프로틴 리스트 카드 클릭
- 식별자: `useLocalSearchParams().id`
- 데이터 소스: Supabase `proteins` + `protein_price_history`
- 조회 전략: 상세 정보와 가격 히스토리를 병렬 조회

## 화면 구성
- 헤더: 제품명 + 가격 등급 + 용량 / 카테고리 / 맛
- 특징 리스트
- 현재가 카드
- 가격 추이 차트
- 구매 버튼

## 데이터 규칙
- `useQuery(['protein', id])`
- 제품이 없으면 not found 상태
- 가격 이력이 1개 이하이면 차트 대신 현재가만 표시
- 구매 URL이 없으면 버튼 비활성화 또는 숨김
