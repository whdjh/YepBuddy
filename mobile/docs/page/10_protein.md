# 10. 프로틴 목록·상세

프로틴 상품과 최신 가격을 비교하고 상품별 가격 이력을 확인하는 화면이다. 가격 차트는 운동 결과의 심박수 차트와 같은 공용 스타일과 점 선택 동작을 사용한다.

## 진입

| 화면 | 라우트 | 구현 |
| --- | --- | --- |
| 목록 | `/(tabs)/protein` | [ProteinListScreen](../../src/features/view-proteins/ui/ProteinListScreen.tsx) |
| 상세 | `/protein/[id]` | [ProteinDetailScreen](../../src/features/view-protein-detail/ui/ProteinDetailScreen.tsx) |

프로틴 탭의 노출은 탭 레이아웃의 `PROTEIN_TAB_ENABLED` 설정을 따른다. 목록 카드에서 해당 상품 상세로 이동하며, 상세의 뒤로 버튼은 이전 화면으로 돌아간다. 상세 라우트에는 진행 중 운동 복귀를 처리하는 `WorkoutNavigationGuard`가 연결되어 있다.

## 목록

- 상품 목록과 최신 가격을 함께 조회해 상품별 카드로 표시한다. 카드에는 상품명, 용량·분류·맛, 현재 가격과 가격 등급을 표시한다.
- 전체, WPC, WPI, WPC/WPI, 크레아틴, 베타알라닌 필터로 조회된 목록을 좁힌다. 최초 선택은 전체다.
- 조회 중, 조회 실패, 선택한 분류에 상품 없음 상태를 화면 안의 문구로 구분한다.
- 쿠팡 파트너스 안내를 목록에 표시한다.

## 상세

- 상품 정보, 가격 이력, 맛 정보를 함께 조회한다. `id`가 없거나 상품을 찾지 못하면 상품 없음 문구를 표시하며, 조회 실패는 별도 오류 문구로 표시한다.
- 상품명과 가격 등급, 용량·분류·맛, 현재 가격, 단백질 1g당 가격, 설명·맛 특징, 가격 추이를 표시한다. 가격이 없으면 `-`를 사용한다.
- 쿠팡 파트너스 안내를 표시한다. 하단 구매 버튼은 비활성 상태다.

## 가격 차트

- 가격 이력은 기본 최대 180개를 조회하고 오래된 관측일부터 표시한다. 날짜가 없거나 가격이 유한한 숫자가 아니면 차트 입력에서 제외한다.
- X는 관측 순서, Y는 가격이다. 날짜 사이의 실제 시간 간격으로 X를 늘리지 않는다. 유효 point가 2개 미만이면 차트 카드를 숨긴다.
- 심박수와 같은 accent 토큰 색상, 높이 160, 영역 채움과 최고·최저 가이드를 사용한다. 가격 통계는 최고·최저만 표시하며 평균 문구·평균 안내선은 표시하지 않는다.
- 차트 영역을 누르면 화면 X/Y 좌표에서 가장 가까운 point를 선택한다. 선택 원과 세로선을 표시하고 차트 위 고정 영역에 관측 날짜와 원화 가격을 보여준다. 손을 떼어도 선택값이 남는다.
- 선택 전 안내 문구는 표시하지 않는다. VoiceOver·TalkBack에서는 이전·다음 조절 동작으로 point를 탐색한다.
- `PriceTrendChart`는 순서·가격 point와 날짜·원화 formatter, 양 끝 라벨을 전달한다. 색상, 통계, 렌더링, 점 선택 상태와 접근성 처리는 모두 [MetricChart](../../src/shared/ui/MetricChart.tsx)가 담당한다. 상세 공용 계약은 [Shared Guide](../../src/shared/README.md#metricchart)를 따른다.

## 데이터와 확인 범위

- 상품·가격·맛 조회는 [proteinApi](../../src/entities/protein/api/proteinApi.ts), 화면 데이터 조립은 [adapters](../../src/entities/protein/model/adapters.ts)가 담당한다. 데이터는 Supabase에서 조회하며 상품·가격을 별도 로컬 저장하지 않는다.
- 가격 등급은 조회된 가격 통계와 앱의 배지 계산을 사용한다. 모바일 코드만으로 서버의 가격 수집 주기나 운영 데이터의 최신성을 보장하지 않는다.
- iOS·Android의 실제 화면, light/dark, 점 선택 및 스크린리더 동작은 실행 검증으로 확인한다. 이 문서는 검증 완료 기록을 대신하지 않는다.
