# 템포 페이지 기능서

> 현재 구현 기준으로 정리한 문서.  
> 범위: `템포 탭 진입 → 템포 설정 → 30초 준비 카운트다운 → 세트/횟수 진행 → 종료`

## 1. 문서 목적

이 문서는 YepBuddy의 템포 페이지가 어떤 역할을 하는지, 사용자가 어떤 흐름으로 이용하는지, 어떤 상태 전환과 예외를 가지는지를 비즈니스 관점에서 이해할 수 있도록 정리한 기능서다.

기획 아이디어나 희망사항이 아니라, 현재 코드에 연결되어 있는 실제 동작을 기준으로 작성한다.

## 2. 기능 한눈에 보기

템포 페이지는 운동 중 특정 리듬을 유지할 수 있도록 돕는 보조 타이머 화면이다.

핵심 역할은 4가지다.

1. 수축/이완 순서와 시간을 미리 설정하게 한다.
2. 세트, 횟수, 휴식 시간을 기준으로 반복 템포를 자동 진행한다.
3. 화면, 사운드, 햅틱으로 현재 구간을 즉시 인지하게 한다.
4. 앱이 잠시 백그라운드에 갔다 와도 경과 시간을 다시 계산해 이어서 보여준다.

## 3. 사용자 흐름

```text
하단 탭 바
  └─ 템포 탭 진입
      └─ 템포 설정 화면
          ├─ 수축 먼저 / 이완 먼저 선택
          ├─ 수축 시간 조절
          ├─ 이완 시간 조절
          ├─ 횟수 조절
          ├─ 세트 수 조절
          └─ 휴식 시간 조절
              └─ 시작 버튼 탭
                  └─ 30초 준비 카운트다운
                      ├─ 남은 10초 경고음/햅틱
                      └─ 템포 진행 시작
                          ├─ 수축 또는 이완 구간
                          ├─ 반대 구간
                          ├─ 횟수 카운트 구간(1초)
                          ├─ 세트 간 휴식
                          └─ 마지막 세트 종료
                              ├─ 성공 햅틱
                              └─ 대기 상태로 초기화
```

## 4. 화면 범위

| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 템포 페이지 | `/tempo` | 템포 설정과 실행을 한 화면에서 처리하는 타이머 도구 |

참고:

- 라우트 파일 `src/app/(tabs)/tempo.tsx`는 엔트리 역할만 한다.
- 실제 기능은 `src/features/use-tempo` 내부에 구현되어 있다.
- 별도의 결과 화면이나 상세 화면으로 이동하지 않는다.

## 5. 화면별 기능

### 5.1 템포 페이지 진입

사용자는 하단 탭 바의 `템포` 탭을 눌러 페이지에 진입한다.

현재 동작 기준:

- 별도 온보딩이나 사전 권한 요청 없이 바로 진입한다.
- 진입 시 기본 설정값이 즉시 보인다.
- 초기 상태는 아직 시작하지 않은 `대기 중` 상태다.
- 일반 템포 탭 진입에서는 우상단 설정 버튼으로 설정 화면에 들어갈 수 있다.
- 운동 중 화면에서 `fromWorkout=1`로 돌아온 템포 화면에서는 운동 복귀 동선을 우선해 설정 버튼을 표시하지 않는다.

기본값:

- 진행 순서: 수축 먼저
- 수축: `3초`
- 이완: `3초`
- 횟수: `10회`
- 세트 수: `3세트`
- 휴식: `60초`

### 5.2 진행 모드 선택

사용자는 두 가지 진행 모드 중 하나를 선택할 수 있다.

선택 가능한 모드:

- 수축 먼저
- 이완 먼저

동작 규칙:

- 두 모드 중 하나만 선택된다.
- 선택된 모드는 버튼 강조 스타일로 표시된다.
- 시작 전에는 자유롭게 바꿀 수 있다.
- 타이머가 시작되면 모드 버튼은 비활성화된다.

### 5.3 템포 설정

사용자는 스테퍼 UI를 통해 템포 설정을 조절할 수 있다.

조절 가능한 항목:

- 수축 시간
- 이완 시간
- 횟수
- 세트 수
- 휴식 시간

동작 규칙:

- 수축 시간 최소값은 `1초`다.
- 이완 시간 최소값은 `1초`다.
- 횟수 최소값은 `1회`다.
- 세트 수 최소값은 `1세트`다.
- 휴식 시간 최소값은 `0초`다.
- 휴식 시간은 `-10`, `-1`, `+1`, `+10` 단위 조절을 지원한다.
- 다른 항목은 `-1`, `+1` 단위 조절이다.
- 타이머가 실행 중이면 모든 설정 입력은 잠긴다.

현재 구현 기준 보이는 특징:

- 최대값 제한은 없다.
- 입력 필드 직접 타이핑은 없고 버튼형 스테퍼만 사용한다.
- 값 변경은 즉시 화면 상태에 반영되지만 별도 저장소에는 저장하지 않는다.

### 5.4 시작 버튼

사용자는 시작 버튼을 눌러 템포 타이머를 실행한다.

동작 규칙:

- 대기 상태에서만 시작 버튼이 보인다.
- 시작 버튼을 누르면 즉시 준비 카운트다운으로 전환된다.
- 실행 중에는 시작 버튼이 사라진다.

현재 구현 기준 제약:

- 실행 중 일시정지 버튼이 없다.
- 실행 중 수동 종료 버튼이 없다.
- 한 번 시작하면 전체 흐름을 끝까지 진행하거나 화면을 벗어나는 방식으로만 종료된다.

### 5.5 준비 카운트다운

시작 직후에는 본 템포 진행 전에 준비 카운트다운이 먼저 실행된다.

사용자에게 보이는 기능:

- 원형 진행 링
- 남은 초 숫자 표시
- 상단 상태 라벨 `준비 중`

동작 규칙:

- 카운트다운 시간은 고정 `30초`다.
- 화면 중앙에는 남은 초가 표시된다.
- 진행 링은 30초 기준으로 채워진다.
- 카운트다운 동안 현재 세트와 현재 횟수는 `0`으로 유지된다.
- 남은 시간이 `10초`가 되는 시점에 경고 사운드와 햅틱이 1회 실행된다.

이 화면의 의미:

- 사용자는 자세를 잡거나 호흡을 정리할 수 있다.
- 시스템은 실제 운동 리듬 시작 전에 준비 시간을 제공한다.

### 5.6 템포 진행

카운트다운이 끝나면 설정값 기준으로 템포가 자동 진행된다.

진행 단위:

1. 첫 번째 구간: 수축 또는 이완
2. 두 번째 구간: 반대 구간
3. 카운트 구간: `1초`

반복 규칙:

- 위 3단계를 1회 반복으로 본다.
- 설정한 횟수만큼 반복하면 한 세트가 끝난다.
- 마지막 세트를 제외한 각 세트 종료 뒤에는 휴식 구간이 들어간다.
- 마지막 세트에는 휴식 구간이 없다.

모드별 구간 순서:

- 수축 먼저: 수축 → 이완 → 카운트
- 이완 먼저: 이완 → 수축 → 카운트

구간별 피드백:

- 수축 구간: `pip` 사운드 + 중간 강도 햅틱
- 이완 구간: `pik` 사운드 + 가벼운 햅틱
- 카운트 구간: 현재 횟수 숫자 음성 재생 시도
- 휴식 시작: 휴식 시작 사운드 + 경고형 햅틱
- 휴식 10초 남음: 경고 사운드 + 강한 햅틱
- 전체 완료: 성공 햅틱

화면 표시 요소:

- 상단 상태 라벨: 현재 구간명
- 중앙 링: 현재 구간 진행률
- 중앙 숫자: 현재 세트
- 보조 텍스트: `현재 세트 / 총 세트`
- 하단 요약: 현재 세트 / 현재 횟수 / 현재 구간

### 5.7 세트 간 휴식

세트가 끝나면 마지막 세트를 제외하고 휴식 단계가 들어간다.

동작 규칙:

- 휴식 시간은 설정값 기준으로 초 단위 계산된다.
- 휴식 시작 순간 별도 사운드와 햅틱이 발생한다.
- 휴식이 `10초` 남았을 때 경고 사운드와 햅틱이 발생한다.
- 휴식 시간이 `0초`이면 휴식 단계는 길이 없이 바로 다음 세트로 넘어간다.

현재 구현 기준의 기술적 특성:

- 내부적으로는 남은 휴식 시간이 계산된다.
- 다만 현재 UI에는 남은 휴식 초가 별도 텍스트로 노출되지 않는다.

### 5.8 완료 처리

마지막 세트의 마지막 횟수까지 끝나면 템포 세션이 종료된다.

종료 시 처리 순서:

1. 내부 타이머를 중지한다.
2. 현재 세트, 횟수, 진행률을 초기화한다.
3. 성공 햅틱을 1회 발생시킨다.
4. 화면 상태를 다시 `대기 중`으로 돌린다.
5. 시작 버튼을 다시 노출한다.

종료 후 상태:

- 설정값은 그대로 남아 다시 실행할 수 있다.
- 별도 기록 저장은 하지 않는다.
- 다른 페이지로 자동 이동하지 않는다.

## 6. 상태와 계산 방식

### 6.1 시간 계산 기준

현재 템포는 실시간 카운터를 초마다 누적하는 방식이 아니라, 시작 시각과 현재 시각의 차이를 기준으로 위치를 다시 계산한다.

사용자 관점의 의미:

- 일시적인 프레임 드롭이 있어도 전체 진행 위치가 크게 틀어지지 않는다.
- 앱이 다시 활성화되면 현재 시점 기준으로 구간을 다시 맞춘다.

### 6.2 실행 중 입력 잠금

타이머가 실행 중이면 아래 입력이 모두 잠긴다.

- 진행 모드 선택
- 수축 시간
- 이완 시간
- 횟수
- 세트 수
- 휴식 시간

사용자 관점의 의미:

- 실행 중 규칙이 바뀌어 세트 계산이 꼬이는 상황을 막는다.

## 7. 오디오, 햅틱, 앱 상태 처리

### 7.1 오디오 동작

현재 구현은 `expo-audio`를 사용해 템포 화면 마운트 시 오디오 모드를 초기화한다.

동작 특성:

- 무음 모드에서도 재생 시도한다.
- 백그라운드 재생을 허용하도록 설정한다.
- 다른 오디오를 완전히 끊기보다 함께 재생되도록 설정한다.

### 7.2 햅틱 동작

현재 구현은 단계별로 다른 강도의 햅틱을 사용한다.

- 수축: Medium impact
- 이완: Light impact
- 휴식 시작: Warning notification
- 휴식 10초 전: Heavy impact
- 완료: Success notification

### 7.3 앱 백그라운드 후 복귀

앱이 백그라운드에 갔다가 다시 활성화되면 현재 시작 시각을 기준으로 템포 위치를 다시 계산한다.

복귀 동작:

- 화면이 살아 있는 상태에서 앱이 다시 `active`가 되면 즉시 한 번 동기화한다.
- 사용자는 복귀 후 현재 세트/횟수/구간을 다시 볼 수 있다.

중요한 한계:

- 실행 상태 자체를 저장하지는 않는다.
- 앱이 화면과 함께 완전히 종료되거나 라우트가 언마운트되면 세션은 유지되지 않는다.

## 8. 권한 및 예외 케이스

### 8.1 오디오 재생 실패

- 오디오 초기화나 특정 사운드 재생에 실패해도 화면 로직 자체는 계속 진행된다.
- 현재 코드에는 오디오 실패 시 사용자용 에러 메시지 표시가 없다.

### 8.2 햅틱 사용 불가

- 기기에서 햅틱이 지원되지 않거나 실패해도 템포 진행은 계속된다.
- 시각적 상태 표시는 유지된다.

### 8.3 횟수를 20회보다 크게 설정한 경우

- 현재 카운트 음성 파일은 `1`부터 `20`까지만 준비되어 있다.
- `21회` 이상으로 설정하면 21회 이상 구간에서는 숫자 음성이 재생되지 않는다.
- 템포 계산과 화면 진행 자체는 계속된다.

### 8.4 화면 이탈 또는 언마운트

- 템포 화면이 언마운트되면 오디오 플레이어를 정리한다.
- 진행 중 세션은 별도로 저장되지 않는다.
- 다시 들어오면 기본 대기 상태에서 시작한다.

## 9. 저장 데이터

현재 구현 기준으로 템포 페이지는 로컬 저장소에 별도 데이터를 남기지 않는다.

| 구분 | 저장 내용 | 목적 |
| --- | --- | --- |
| 진행 중 스냅샷 | 없음 | 진행 상태 복원 기능 미구현 |
| 완료 기록 | 없음 | 세션 기록 보관 기능 미구현 |
| 사용자 설정 저장 | 없음 | 마지막 설정값 유지 기능 미구현 |

## 10. 현재 기능 기준에서 꼭 알아야 할 제약

### 10.1 일시정지 / 재개 기능이 없음

- 시작 후 중간에 멈추거나 다시 이어서 가는 버튼이 없다.

### 10.2 수동 종료 버튼이 없음

- 사용자가 현재 세션을 즉시 중단하는 전용 버튼이 없다.

### 10.3 실행 상태 복원 기능이 없음

- 운동 화면과 달리 진행 중 템포를 AsyncStorage 등에 저장하지 않는다.
- 앱 종료나 화면 이탈 후 자동 복원되지 않는다.

### 10.4 결과 요약 화면이 없음

- 세션 완료 후 기록 요약, 히스토리, 통계 화면으로 이어지지 않는다.

### 10.5 준비 시간은 고정 30초

- 사용자가 준비 카운트다운 길이를 바꿀 수 없다.

### 10.6 휴식 잔여 시간은 내부 계산만 하고 화면에는 직접 보여주지 않음

- 휴식 단계 여부는 보이지만, 몇 초 남았는지 숫자로 확인하는 UI는 없다.

## 11. 이 페이지가 제공하는 비즈니스 가치

이 템포 페이지는 운동 기록을 저장하는 기능보다, 사용자가 실제 운동 리듬을 일정하게 유지하게 돕는 실행 보조 도구에 가깝다.

가치는 다음과 같다.

1. 사용자가 리듬을 직접 세지 않아도 되므로 운동 집중을 돕는다.
2. 수축/이완/휴식 구간을 일관된 방식으로 반복하게 한다.
3. 시각, 청각, 촉각을 함께 사용해 현재 구간 인지를 쉽게 만든다.
4. 템포 운동을 빠르게 시작할 수 있어 별도 타이머 앱 의존을 줄인다.

## 12. 요약

현재 YepBuddy의 템포 페이지는 “설정값을 입력하고, 30초 준비 후, 수축/이완/카운트/휴식을 자동으로 반복 안내하는 단일 화면 타이머”다.

사용자는 모드와 시간을 간단히 설정한 뒤 바로 시작할 수 있고, 앱은 그에 맞춰 구간 진행률, 현재 세트, 현재 횟수, 사운드, 햅틱을 제공한다. 다만 운동 기록 저장, 실행 중 복원, 일시정지/수동 종료 같은 세션 관리 기능은 아직 연결되어 있지 않으며, 현재 페이지의 핵심 역할은 기록이 아니라 리듬 안내에 있다.
