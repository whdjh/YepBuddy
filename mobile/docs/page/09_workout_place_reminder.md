# 운동 장소 도착 알림 기능서

> 현재 구현 기준으로 정리한 canonical 문서.
> 범위: `설정에서 운동 장소 등록 → 50m Enter-only geofence 등록 → 현재 위치 20m 재검증 → 장소 도착 알림 → 운동 시작 확인`

## 1. 기능 목적

사용자가 설정에서 직접 등록한 헬스장에 실제로 도착했을 때 OS 로컬 알림으로 운동 시작을 제안한다.

이 기능은 운동 기록을 자동으로 시작하지 않는다. 알림을 누른 뒤 운동일지에서 확인 Alert를 띄우고, 사용자가 `운동 시작`을 선택해야 카운트다운으로 이동한다.

OS geofence는 best-effort 기능이다. 특히 Android에서 사용자가 앱을 강제 종료하면 Enter 이벤트가 전달되지 않을 수 있으므로, 20m 안에서 알림이 항상 보장되지는 않는다. 50m geofence는 앱을 깨우는 후보 신호일 뿐이며 실제 알림 기준은 20m다.

## 2. 운동 장소 등록

- 사용자는 설정 화면에서 현재 위치를 운동 장소로 등록한다.
- 등록 가능한 운동 장소는 한 번에 1곳뿐이다.
- 등록 시 현재 위치와 위치 정확도를 함께 확인한다.
- 위치 정확도가 `20m` 이내일 때만 등록한다.
- 위치를 얻지 못하거나 정확도가 `20m`보다 나쁘면 기존 등록 위치를 바꾸지 않고 실패를 안내한다.
- 재등록하면 기존 위치를 새 현재 위치로 교체한다. 알림이 ON이면 geofence도 다시 등록하고, OFF이면 다음 ON까지 위치만 보관한다.
- 운동 완료 위치를 후보로 누적하거나, 120m 기준으로 병합하거나, 2회 이상 방문 여부를 계산하지 않는다.

## 3. Geofence 등록

- 등록된 단일 운동 장소를 중심으로 반경 `50m` geofence 1개만 등록한다.
- `Location.startGeofencingAsync()`로 Enter 감지를 등록한다.
- `TaskManager.defineTask()`는 앱 번들 로드 시 전역 scope에서 등록된다.
- Enter 이벤트만 처리하며 Exit 이벤트와 운동 종료 누락 리마인더는 사용하지 않는다.
- 장소 알림을 OFF 하면 등록 위치는 유지하고 `Location.stopGeofencingAsync()`로 geofence만 중지한다.
- 등록 해제를 하면 저장된 위치를 삭제하고 알림도 OFF로 전환한 뒤 geofence를 중지한다.

## 4. 권한 원칙

- 설정 화면에서 사용자가 운동 장소 등록 또는 재등록을 선택하면 foreground 위치 권한만 요청할 수 있다.
- 사용자가 장소 알림 ON을 선택하면 알림 권한, foreground 위치 권한, background 위치 권한을 요청할 수 있다.
- Android 11+에서는 background location 권한 요청 시 시스템 설정 화면으로 이동한다. 앱은 설정 화면으로 보내기 전에 백그라운드 위치가 필요한 이유를 Alert로 설명한다.
- 앱 시작과 자동 재동기화에서는 현재 권한 상태만 확인하고 OS 권한 프롬프트를 띄우지 않는다.
- 자동 동기화에서 알림 또는 위치 권한이 꺼져 있으면 geofence를 중지하고 실제 등록 가능 상태를 저장한다. 사용자가 등록한 위치는 삭제하지 않는다.

## 5. 도착 판정과 알림 규칙

Enter 이벤트는 알림 후보 신호이며 이벤트만으로 바로 알림을 보내지 않는다.

다음 조건을 모두 만족할 때만 알림을 보낸다.

- 권한 프롬프트 없이 현재 위치를 1회 조회할 수 있다.
- 현재 위치 정확도가 `20m` 이내다.
- 현재 위치와 등록된 운동 장소 사이의 거리가 `20m` 이내다.
- 운동 상태가 `idle` 또는 `completed`다. `countdown`, `recording`, `paused` 중에는 보내지 않는다.
- 장소 등록 또는 재등록 후 12시간이 지났다.
- 마지막 운동을 완료한 뒤 12시간이 지났다.
- 마지막 장소 도착 알림 후 12시간이 지났다.

12시간 제한은 등록, 운동 완료, 알림 발송 중 가장 최근 시각을 기준으로 적용한다. 알림 예약이 성공한 경우에만 마지막 알림 시각을 갱신한다.

알림 내용:

- 제목: `운동 장소 근처에 도착했어요`
- 본문: `운동을 시작하시겠어요?`
- data: `type: "workout-place-arrival"`, `placeId: "confirmed-workout-place"`
- 주소, 좌표, 운동 기록 상세는 포함하지 않는다.

장소 유형 분류, context, 최근 위치 sample, 이동 방향, 노이즈 점수, 다중 장소 매칭은 사용하지 않는다.

## 6. 알림 탭 동작

- 알림을 누르면 앱을 열고 운동일지 화면으로 이동한다.
- 운동일지 화면은 pending prompt를 읽고 확인 Alert를 표시한다.
- Alert의 `나중에`를 누르면 pending prompt를 삭제하고 아무 동작도 하지 않는다.
- Alert의 `운동 시작`을 누르면 pending prompt를 삭제한다.
- 진행 중 운동이 없으면 `/workout/countdown`으로 이동한다.
- 이미 진행 중인 운동이 있으면 `/workout/active`로 이동한다.

## 7. 설정 상태

- ON: 등록 위치와 권한이 유효하면 50m Enter geofence를 등록한다.
- OFF: 등록 위치와 cooldown 정보는 유지하고 geofence만 중지한다.
- 재등록: 정확도 조건을 통과한 현재 위치로 교체하고 등록 시각을 갱신한다.
- 등록 해제: 위치와 관련 상태를 삭제하고 OFF로 전환하며 geofence를 중지한다.

## 8. 저장 데이터

- enabled 상태
- 사용자가 등록한 단일 운동 장소의 좌표와 등록/재등록 시각
- pending prompt
- 권한과 geofence 동기화 상태
- 단일 cooldown 기준 시각. 등록/재등록, 운동 완료, 도착 알림 성공 시각 중 마지막 값

자동 장소 후보 배열, 장소 context, 위치 sample, Exit 리마인더 cooldown은 저장하지 않는다.
