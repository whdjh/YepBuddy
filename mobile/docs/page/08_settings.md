# 설정 화면 기능서

> 현재 구현 기준으로 정리한 문서.  
> 범위: `메인 탭 설정 버튼 → 설정 화면 진입 → 루틴 사이클 제어 → 캘린더 자동 저장 제어 → 운동 리마인더 제어 → 운동 장소 도착 알림 제어 → 프로틴 세일 알림 제어`

## 1. 문서 목적

이 문서는 사용자가 직접 제어하는 설정이 어떤 화면으로 모였는지, 각 설정이 어떤 사용자 액션과 권한 요청에 연결되는지를 정리한다.

## 2. 진입 위치

설정 화면은 `/settings` 라우트로 제공된다.

설정 버튼이 보이는 위치:

- 운동일지 탭
- 일반 템포 탭
- 프로틴 탭

운동 중 화면에서 `fromWorkout=1`로 들어온 템포 화면에는 설정 버튼을 표시하지 않는다.

## 3. 설정 항목

### 3.1 루틴 사이클

루틴 사이클 설정은 운동 섹션에 표시된다.

동작:

- 토글 ON 시 루틴 사이클 진행률과 추천 세션을 켠다.
- 토글 OFF 시 저장된 세부 설정은 유지하고 루틴 진행률과 추천 세션만 숨긴다.
- 루틴이 ON이고 세부 설정이 없으면 세부 설정 시트를 연다.
- `세부 설정` 버튼을 누르면 기존 루틴 편집 시트를 연다.
- 최초 루틴 안내에서 `예`를 선택하면 `/settings?routineSetup=1`로 이동해 세부 설정 시트를 연다.

### 3.2 캘린더 자동 저장

캘린더 자동 저장은 운동 섹션에 표시된다.

동작:

- 토글 ON 시 현재 캘린더 권한을 확인한다.
- 권한이 없으면 사용자의 명시적 설정 액션에 이어 캘린더 권한을 요청할 수 있다.
- 권한이 허용되면 `enabled`를 저장하고 이후 운동 완료 시 완료 시간을 기기 캘린더에 자동 추가한다.
- 권한이 거부되면 `disabled`를 저장하고 토글을 OFF로 되돌린 뒤 설정 이동 안내 Alert를 표시한다.
- 토글 OFF 시 `disabled`를 저장하고 이후 운동 완료 시 캘린더 등록을 조용히 건너뛴다.
- 운동 완료 흐름에서 한 번 거절했거나 권한이 거부되어 `disabled`가 저장된 경우, 사용자는 이 토글에서 다시 켤 수 있다.
- 설정 토글은 `yb:workout:calendar:auto-add` 저장값을 `enabled` 또는 `disabled`로 바꾼다.

### 3.3 운동 리마인더

운동 리마인더는 운동 섹션에 표시된다.

동작:

- 사용자가 토글 ON을 누른 경우에만 OS 알림 권한을 요청할 수 있다.
- 권한이 허용되면 오늘 운동 기록을 반영해 다음 22:00 운동 리마인더를 예약하고 enabled 값을 true로 저장한다.
- 권한이 거부되면 enabled 값을 false로 저장하고 토글을 OFF로 되돌린다.
- 토글 OFF 시 enabled 값을 false로 저장하고 기존 예약을 취소한다.

### 3.4 운동 장소 도착 알림

운동 장소 도착 알림은 운동 섹션에 표시된다. 운동 결과 화면의 위치로 자동 학습한 헬스장의 20m 안에 도착했을 때 운동 시작 알림을 보낸다.

동작:

- 기존 수동 `현재 위치 등록` 액션 대신 `등록된 헬스장 위치` 버튼을 표시한다.
- 버튼을 누르면 자동 학습된 장소를 최근 방문 순으로 보여주는 하단시트를 연다.
- 결과 화면에 저장된 위치가 유효한 완료 운동을 한 장소 표본으로 만들고, 기존 장소 `30m` 이내면 같은 장소로 병합한다.
- 하단시트에서 장소를 삭제할 수 있으며 마지막 장소를 삭제하면 알림을 OFF로 전환한다.
- 토글 ON은 OS 알림 권한, foreground 위치 권한, background 위치 권한을 요청할 수 있다.
- 권한이 허용되고 등록 위치가 있으면 앱을 깨우기 위한 반경 `50m` Enter-only geofence를 장소별로 등록하고 enabled 값을 true로 저장한다.
- 권한이 거부되면 enabled 값을 false로 저장하고 토글을 OFF로 되돌린다.
- 토글 OFF 시 enabled 값을 false로 저장하고 geofence를 중지한다. 장소 목록은 유지한다.
- 자동 동기화에서 권한이 꺼져 있으면 enabled 값은 유지하고 실제 등록 가능 상태를 별도로 저장한다.
- enabled 상태지만 실제 등록이 불가능하면 설정 화면 본문에 권한/등록 상태를 함께 표시한다.
- Enter 이벤트 후 현재 위치를 한 번 다시 확인하고, 거리와 정확도가 모두 `20m` 이내일 때만 알림을 발송한다.
- 운동 카운트다운, 기록 중, 일시정지 상태에는 알림을 보내지 않는다.
- 운동을 완료했거나 도착 알림을 발송한 로컬 날짜와 오늘이 같으면 알림을 보내지 않는다. 날짜가 바뀌면 다시 허용한다.
- 알림 탭 시 메인 화면을 거쳐 운동 중/대기 상태에 따라 카운트다운 또는 운동 진행 화면으로 이동한다.

### 3.5 프로틴 세일 알림

프로틴 세일 알림은 프로틴 섹션에 표시된다.

동작:

- 사용자가 토글 ON을 누른 경우에만 OS 알림 권한을 요청할 수 있다.
- 권한이 허용되면 향후 프로틴 세일 알림을 예약하고 enabled 값을 true로 저장한다.
- 권한이 거부되면 enabled 값을 false로 저장하고 토글을 OFF로 되돌린다.
- 토글 OFF 시 enabled 값을 false로 저장하고 기존 예약을 취소한다.

## 4. 권한 원칙

- 앱 시작, 운동 종료, 자동 재동기화 같은 경로에서는 OS 알림 권한 프롬프트를 띄우지 않는다.
- 자동 경로는 저장된 enabled 상태와 현재 OS 권한 상태만 확인한다.
- 사용자가 OS Settings에서 권한을 끈 경우 자동 동기화는 남은 예약이나 geofence를 중지한다. 운동 장소 알림은 등록 위치와 enabled 의도를 유지하고, 다른 예약 알림은 enabled를 false로 맞춘다.
- 알림은 앱 기능 사용의 필수 조건이 아니며, 사용자는 설정 화면에서 쉽게 수신 동의를 철회할 수 있다.
- 캘린더 권한은 사용자가 앱 안의 1회성 캘린더 자동 저장 Alert에서 동의했거나 설정 화면에서 캘린더 자동 저장을 ON 한 경우에만 요청할 수 있다.
- 앱 시작, 알림 action, 운동 완료 자동 처리 같은 백그라운드/자동 경로에서는 캘린더 권한을 요청하지 않는다.
- 캘린더 자동 저장이 꺼져 있거나 권한이 없으면 운동 완료는 정상 처리하고 캘린더 등록만 건너뛴다.
