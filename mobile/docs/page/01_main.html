개요

메인 화면은 사용자가 앱에 진입했을 때 오늘 운동 상태, 최근 세션, 이번 주 실제/예정 루틴, 새 운동 시작, 카드 구성 편집으로 이어지는 요약 허브다. 화면 본문은 SummaryScreen이 담당하고, 탭 엔트리에서는 이 화면 위에 설정 플로팅 버튼을 얹는다.

진입/라우트

메인 탭 엔트리인 src/app/(tabs)/index.tsx는 전체 높이의 View 안에 SummaryScreen과 SettingsFab을 함께 렌더링한다. 설정 버튼은 /settings로 이어지고, 주간 루틴 최초 안내의 수락 액션은 /settings?routineSetup=1로 이동해 세부 설정 시트를 열도록 연결된다.

핵심 책임

오늘 상태 요약

오늘 대표 로컬 세션의 부위/세트와 HealthKit workout duration 합계를 조합한다. HealthKit duration이 없으면 로컬 세션 duration을 fallback으로 쓴다.

이동 허브

오늘 카드는 캘린더, 최근 세션과 주간 실제 행은 결과 화면, 주간 헤더는 세션 목록, 운동 시작 카드는 카운트다운으로 이동한다.

주간 루틴 반영

루틴 ON일 때 실제 세션과 루틴 슬롯을 매칭해 완료/대체/예정 행을 만들고, 운동 중 화면에는 다음 추천 루틴 칩을 제공한다.

요약 카드 편집

카드 표시 여부, 순서, 같은 행 안 좌우 이동을 지원하며 yb:summary:cards에 저장한다. 세션 데이터 자체는 수정하지 않는다.

사용자 흐름

메인 화면은 여러 저장원을 병렬에 가깝게 읽은 뒤 카드 레이아웃 순서에 맞춰 렌더링한다. 일부 조회가 실패하면 해당 훅은 기본값으로 복구하고, 전체 화면 로딩 대신 카드 단위 placeholder를 유지한다.

편집 모드

카드 롱프레스는 편집 모드로 진입한다. 삭제는 현재 카드 배열에서 ID를 제거하고, 추가 모달은 숨겨진 카드만 후보로 보여준다. 전체 너비 카드는 단독 행, 반 너비 카드는 두 개씩 한 행으로 묶이며, 같은 행 안 좌우 이동과 전체 목록 기준 상하 이동이 별도 함수로 처리된다.

데이터 소스

로컬 운동 세션

오늘 대표 세션 ID, 최근 세션, bodyParts, setCount, startedAt/completedAt을 읽는다.

sessionStorage, useTodaySummary, useLatestSession

HealthKit

오늘 날짜 workout 목록의 duration과 kcal을 조회한다. 현재 UI에 직접 노출되는 값은 운동시간이며 kcal은 후속 확장 기반이다.

getWorkoutSummariesForDate(dateKey)

주간 루틴

루틴 기능 상태, 저장 설정, 이번 주 세션을 조합해 진행 슬롯과 다음 추천 세션을 만든다.

useWeeklyRoutinePlan, useRoutineProgress

카드 레이아웃

카드 ID 배열을 yb:summary:cards에 저장하고 불러올 때 유효 ID와 중복을 정리한다.

summaryCardLayoutStorage.ts

상태/예외

로딩과 갱신

useSummaryRefresh는 최초 마운트, 앱 active 복귀, 다음 자정에 재조회한다. 오래된 응답은 requestId로 무시하고, 실패 시 initialData로 복구한다. 오늘 요약 로딩 중 운동시간/세트수는 --로 표시된다.

운동 시작 차단

오늘 날짜 키에 저장된 완료 세션 ID가 있으면 todayCompleted가 true가 되고, 운동 시작 카드는 비활성화된다. 롱프레스 편집은 유지되어 편집 모드 진입은 가능하다.

루틴 행 생성

루틴 슬롯은 pending, partial, completed, substituted 상태를 가진다. 완료/대체 슬롯은 실제 세션 행으로, pending/partial 슬롯은 예정 행으로 렌더링되고, 이미 슬롯에 사용된 세션은 중복 표시하지 않는다.

운동 중 루틴 추천

/workout/active는 루틴 로딩이 끝났고 루틴이 ON일 때만 RoutineSessionPicker를 표시한다. 첫 미완료 슬롯은 1회 자동 선택되며 선택된 루틴 부위 템플릿이 운동 부위 상태에 반영된다.

스펙 ↔ 코드 갭

기본 루틴 개수: md의 4분할 표현과 코드의 5분할 기본값

md 일부 문장은 기본 루틴을 가슴/등/어깨팔/하체 4분할처럼 설명하지만, 현재 DEFAULT_WEEKLY_ROUTINE_SESSIONS는 가슴, 등, 어깨, 팔, 하체 5개 슬롯이고 DEFAULT_WEEKLY_ROUTINE_SPLIT_COUNT도 5다.

카드 레이아웃 저장값 복구 규칙

의도적으로 저장된 빈 배열은 모든 카드를 숨긴 상태로 유지된다. 반면 저장 배열이 비어 있지 않은데 유효 카드 ID가 하나도 없으면 깨진 저장값으로 보고 기본 카드 배열로 복구한다. 이는 normalizeSummaryCardIds가 아니라 loadSummaryCardIds의 실제 로딩 규칙 기준이다.

운동시간 fallback

md는 운동시간을 HealthKit duration 합계로 설명하지만, 코드의 mergeTodaySummary는 HealthKit duration 합계가 0이면 오늘 대표 로컬 세션 duration을 초 단위로 환산해 사용한다.

substituted 슬롯 상태

md는 completed/partial/pending 중심으로 설명하지만, 실제 루틴 진행률에는 substituted가 추가로 있다. 대체 완료 세션은 completed와 같이 완료 행으로 표시되고 추천/칩에서는 비활성 처리된다.
