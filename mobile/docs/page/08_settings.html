개요

사용자가 직접 제어하는 설정이 어떤 화면으로 모였는지, 각 설정이 어떤 사용자 액션과 권한 요청에 연결되는지를 정리합니다.

범위: 메인 탭 설정 버튼 → /settings → 주간 루틴 · 운동 리마인더 · 운동 장소 도착 알림 · 프로틴 세일 알림

3.1 주간 루틴

운동 섹션

동작

  • ●토글 ON → 진행률과 추천 세션을 켠다.
  • ●토글 OFF → 세부 설정은 유지하고 진행률·추천 세션만 숨긴다.
  • ●ON 시 세부 설정이 없으면 설정 시트를 연다.
  • ●세부 설정 버튼은 ON 상태에서만 노출되며 기존 시트를 다시 연다.
  • ●최초 안내에서 예를 선택하면 /settings?routineSetup=1로 이동해 시트를 자동 오픈.

3.2 운동 리마인더

운동 섹션 · 매일 22:00

동작

  • ●사용자가 토글 ON을 누른 경우에만 OS 알림 권한을 요청 (allowPrompt:true).
  • ●권한 허용 → 오늘 운동 기록을 반영해 다음 22:00 리마인더를 예약, enabled=true.
  • ●권한 거부 → enabled=false로 저장하고 토글 OFF로 되돌림.
  • ●토글 OFF → enabled=false 저장 + 기존 예약 취소.
22:00 결정 규칙

getNextWorkoutReminderDate: 오늘 22:00이 이미 지났거나 오늘 운동 기록이 있으면 내일 22:00으로 미룬다.

3.3 운동 장소 도착 알림

운동 섹션 · geofence 150m

동작

  • ●토글 ON 시 알림 → FG 위치 → BG 위치 순서로 권한 요청. Android는 BG 권한 요청 전 안내 Alert.
  • ●모두 허용 + 2회 이상 운동한 장소 존재 → geofence 등록, enabled=true, operational=true.
  • ●권한 OK · 등록할 장소 없음 → enabled=true, operational=false, reason no-places.
  • ●권한 거부 → enabled=false, 토글 OFF로 복귀.
  • ●토글 OFF → disableWorkoutPlaceArrivalReminder: geofencing 중지 + reason disabled.
  • ●자동 동기화에서 권한이 꺼져있으면 enabled는 유지하고 operational=false만 저장.
  • ●enabled이지만 operational 아닐 때 설정 화면 본문에 권한/등록 상태 메시지 표시.

3.4 프로틴 세일 알림

프로틴 섹션

동작

  • ●토글 ON 시에만 OS 알림 권한 요청 (requestProteinSaleNotificationPermissions).
  • ●허용 → 채널 보장 + 기존 예약 취소 + buildProteinSaleNotificationPlans로 향후 세일 알림 일괄 예약, enabled=true.
  • ●권한 거부 → enabled=false로 저장, 토글 OFF.
  • ●토글 OFF → disableProteinSaleNotifications: enabled=false + 저장된 예약 id 전체 취소.
  • ●알림 작업은 직렬 큐(runProteinSaleNotificationTask)로 처리해 동시 호출 충돌을 방지.

권한 원칙

자동 경로

앱 시작 · 운동 종료 · 자동 재동기화에서는 OS 권한 프롬프트를 띄우지 않는다. 저장된 enabled와 현재 권한 상태만 확인한다.

allowPrompt: false

사용자 명시 ON

사용자가 토글 ON을 누른 경우에만 권한을 요청한다. 거부 시 모든 항목은 enabled=false로 복구된다.

allowPrompt: true

OS Settings에서 권한 끔

자동 동기화가 이를 감지하면 enabled를 false로 맞추고 남은 예약·등록을 취소한다 (운동 장소 알림은 enabled를 유지하고 operational만 false 처리).

선택 사항

알림은 앱 기능 사용의 필수 조건이 아니다. 사용자는 설정 화면에서 언제든 수신 동의를 철회할 수 있다.

[추가 설명] 운동 장소 알림 — 자동 경로에서 enabled 처리

코드(syncWorkoutPlaceArrivalReminder)는 allowPrompt:false 자동 경로에서 권한이 부족해도 enabled를 강제로 false로 바꾸지 않고 operational=false만 기록한다 — 그래서 사용자가 OS에서 권한을 다시 켜면 enabled가 유지된 채 자동 복구 가능. 스펙 4번 마지막 줄과 합치.

[보강 필요] 주간 루틴 토글 OFF 동작

스펙은 “세부 설정은 유지하고 진행률만 숨긴다”고 적혀있고, 코드는 featureStatus만 'disabled'로 바꾸므로 일치. 다만 설정 시트를 빈 상태로 닫으면 shouldDisableOnSheetCloseRef로 자동 OFF 되는 시나리오는 스펙에 명시되지 않음.
