개요

운동 장소 도착 알림은 완료 운동의 위치 히스토리를 누적해 반복 장소를 찾고, 사용자가 해당 장소 근처에 다시 도착하면 운동 시작을 제안하는 로컬 알림 기능이다.

범위: 완료 세션 위치 누적 → 반복 장소 선택 → 권한 동의 → geofence 등록 → Enter 알림 → 운동 시작 Alert

장소 판정

위치가 있는 완료 세션만 장소 후보에 반영된다. 새 세션 위치가 기존 장소 중심점에서 120m 이내면 같은 장소로 보고 운동 횟수와 중심점을 갱신한다.

  • ●새 장소의 id는 최초 세션의 sessionId를 사용한다.
  • ●기존 장소와 병합되면 workoutCount가 증가한다.
  • ●중심 좌표는 이전 중심점과 새 좌표의 누적 평균으로 이동한다.
  • ●운동 기록 삭제 후에는 남은 완료 세션 전체로 장소 히스토리를 다시 만든다.

Geofence 등록

등록 후보는 workoutCount >= 2인 장소만 포함한다. 후보가 20개를 넘으면 최근 운동일, 같은 날이면 운동 횟수 기준으로 상위 20개만 OS geofence에 등록한다.

등록 성공

Location.startGeofencingAsync에 장소 id, 위도, 경도, 반경 150m, enter/exit 감지 옵션을 전달한다. 성공하면 enabled=true, operational=true, reason registered로 저장한다.

등록 실패/중지

권한 부족, 후보 없음, 등록 실패, 사용자의 OFF 액션에서는 Location.stopGeofencingAsync로 기존 등록을 중지하고 sync status에 reason을 기록한다.

권한 체인

권한 요청은 설정 화면에서 사용자가 운동 장소 도착 알림을 ON 하는 명시적 액션에서만 가능하다. 앱 시작, 운동 종료, 기록 삭제 후 재동기화는 현재 권한만 확인한다.

알림 규칙

Enter 이벤트만 발송

geofence task는 Enter와 Exit 모두 상태에 저장하지만, 실제 로컬 알림은 Enter 이벤트에서만 예약한다.

하루 1회 제한

장소의 lastNotifiedDateKey가 오늘이면 알림을 보내지 않는다. 발송 직전 오늘 날짜 키로 갱신한다.

알림 내용

제목/본문은 번역 키 workoutPlaceReminder.notification.*를 사용한다. data에는 type과 placeId만 들어간다.

제공 보장 한계

OS geofence 이벤트에 의존하므로 알림이 지연되거나 누락될 수 있다. 앱은 마지막 이벤트 상태를 sync status에 남긴다.

탭 후 동작

알림 탭 자체가 운동을 자동 시작하지 않는다. 응답 핸들러는 pending prompt를 저장하고 운동일지로 이동시킨다. 운동일지 화면이 포커스되면 확인 Alert를 띄운다.

[일치] md의 핵심 수치와 코드가 일치

장소 병합 120m, geofence 150m, 2회 이상 후보, 최대 20개 등록, 하루 1회 알림 제한은 코드 상수와 구현에서 확인된다.

[보강] Exit 이벤트는 알림 발송 없이 상태만 저장

md는 Enter 이벤트 중심으로 설명한다. 코드에서는 Exit도 saveWorkoutPlaceReminderSyncEvent에 기록하지만, 알림 발송은 Enter에서만 수행한다.

[보강] 기록 삭제 후 장소 히스토리 재생성

결과 화면의 삭제 흐름은 세션 삭제 후 남은 완료 세션으로 장소 히스토리를 다시 만들고, 권한 프롬프트 없이 geofence를 재동기화한다.
