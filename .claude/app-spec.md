# YepBuddy 앱 명세서

> **최종 수정**: 2026-03-24

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 앱 이름 | **yepbuddy** (입에 착 붙는 헬스장 추임새) |
| 목표 | '확장형 알약 UI'와 '카멜레온 UI'를 활용해 조작을 최소화한 미니멀리즘 iOS 피트니스 앱 |
| 플랫폼 | iOS 전용 (React Native Expo / TypeScript) |
| 디자인 시스템 | Earthen UI (크림, 모래, 대지톤의 감성적인 내추럴 테마) |

---

## 2. 기술 스택 및 라이브러리

### 코어

| 역할 | 라이브러리 |
|------|-----------|
| 애니메이션 | `react-native-reanimated` |
| 상태 관리 | `Zustand` + `AsyncStorage` |
| 데이터 페칭 | `@tanstack/react-query` |
| 오디오 | `expo-av` |
| 네비게이션 | `expo-router` |

### 추가

| 역할 | 라이브러리 |
|------|-----------|
| 캘린더 연동 | `expo-calendar` |
| 설정 앱 유도 | `expo-linking` |
| SVG 렌더링 | `react-native-svg` (원형 프로그레스 바) |
| DB 클라이언트 | `@supabase/supabase-js` |
| 날짜 처리 | `dayjs` |
| 햅틱 피드백 | `expo-haptics` |

---

## 3. 글로벌 UI: 알약 네비게이션

- **구조:** 화면 하단 중앙에 플로팅되는 단일 네비게이션 바.
- **기본 상태:** 현재 화면 아이콘만 표시하여 화면 점유 최소화.
- **터치 시:** `react-native-reanimated`를 통해 가로 확장, `[ 일지 | 템포 | 프로틴 ]` 선택지 노출.
- **햅틱:** 확장/축소 시 `expo-haptics` 경량 진동 피드백.

---

## 4. 전체 화면 맵 (개발 순서)

```
Phase 1: 핵심 운동 플로우
├─ 1. 카운트다운 → 운동중 화면 (운동 실행 + 기록 입력)
└─ 2. 운동 결과 화면 (운동 완료 후 확인)

Phase 2: 데이터 조회
├─ 3. 메인화면 - 요약 (대시보드)
│   ├─ 오늘의 운동 카드 → 5. 캘린더 페이지
│   │                       └─ 캘린더 항목 클릭 → 2. 운동 결과 화면
│   ├─ 세션 카드 → 2. 운동 결과 화면
│   ├─ 이번주 세션 "더보기" → 4. 세션 목록 화면
│   │                          └─ 세션 항목 클릭 → 2. 운동 결과 화면
│   └─ 운동 카드 → 1. 카운트다운 → 운동중 화면 (바로 진입)
├─ 4. 세션 목록 화면 (전체 세션 히스토리)
└─ 5. 캘린더 페이지
    └─ 캘린더 항목 클릭 → 2. 운동 결과 화면

Phase 3: 부가 기능
├─ 6. 운동 템포 페이지
├─ 7. 프로틴 페이지
└─ 8. 프로틴 상세 페이지

Phase 4: 위젯
└─ 9. 잠금화면 위젯
```

# Phase 1: 핵심 운동 플로우

---

## 1. 카운트다운 → 운동중 화면

| 항목 | 내용 |
|------|------|
| **진입 경로** | 메인화면 운동 카드 클릭 → 바로 진입 (사전 입력 없음) |
| **특이사항** | 2단계로 구성 (카운트다운 → 운동중) |

### 1-A. 카운트다운 화면
- 전체화면, 큰 원형 프로그레스
- 중앙에 카운트다운 숫자 (3, 2, 1...)
- 부위 아이콘 + "근력 강화 운동" 텍스트

### 1-B. 운동중 화면

#### 메인 영역 (스크롤 가능)
- 실시간 심박수 (큰 숫자 + 하트 아이콘)
- 활동 킬로칼로리 / 총 킬로칼로리 (2열)
- **운동 부위 선택** — 칩(Chip) 형태: 가슴 | 등 | 하체 | 어깨 | 팔 | 코어 (단일 선택, 선택 안 해도 됨)
- **세트수 입력** — 숫자 표시 (기본값 0, 입력 안 해도 됨)
- **메모 입력** — 텍스트 영역, 플레이스홀더: "운동 메모를 자유롭게 작성하세요..."

#### 하단 드로어(Drawer)
- 부위 아이콘 + 타이머(MM:SS.ms) + 세트 프로그레스 링
- 중지 버튼 (전체 너비)
- 운동 종료 버튼 (전체 너비)

### 상태 관리
- Zustand 전역 스토어에 `phase: 'recording' | 'completed'` 필드로 운동 단계 관리
- 디바운싱(1초) 후 Zustand 스토어 + AsyncStorage에 자동 저장. 앱 재진입 시 즉시 복원

### 상세 내용
- **사전 입력 없음**: 운동카드 클릭 → 바로 카운트다운 → 운동중으로 진입. 부위/세트/메모는 운동중에 선택적으로 입력
- **카운트다운**: 3, 2, 1 고정 (설정 불가)
- **운동 종료**: 드로어의 운동 종료 버튼 클릭
- **캘린더 등록**: 운동 종료 시 자동으로 캘린더에 기록 (별도 버튼 없음)
- **세션 제한**: 하루 1세션 고정

### 캘린더 퍼미션 플로우 (`expo-calendar` + `expo-linking`)

```
트리거: 운동 종료 시 캘린더 등록 최초 시도
├─ undetermined → requestCalendarPermissionsAsync() → iOS 시스템 팝업
├─ granted → 일정 등록 실행
├─ denied → 커스텀 모달 표시
│   ├─ "설정으로 이동" → Linking.openSettings()
│   └─ "나중에" → 모달 닫기, 등록 스킵
└─ 재진입 시 → getCalendarPermissionsAsync()로 상태 재확인
```

> Just-in-Time 방식 채택: 유저가 캘린더 기능을 처음 사용하는 시점에 권한 요청.

## 2. 운동 결과 화면 (세션 상세)

| 항목 | 내용 |
|------|------|
| **진입 경로** | 운동 종료 후 / 세션 목록에서 세션 카드 클릭 / 캘린더 항목 클릭 |
| **네비게이션** | ← 뒤로가기, 타이틀 날짜 (예: "3월 15일") |

### 구성 요소

**① 세션 헤더**
- 부위 아이콘 + 부위명
- 날짜 + 총 운동 시간

**② 메모**
- 사용자가 작성한 운동 메모 (예: "벤치프레스 무게 올림 80kg 성공")

**③ 운동 세부사항** (2×2 그리드)
- 운동 시간 (H:MM:SS)
- 활동 칼로리 (KCAL)
- 세트수
- 평균 심박수 (BPM)

**④ 심박수 차트**
- 시간 흐름에 따른 심박수 라인 차트
- 시작 ~ 종료 구간
- 평균 심박수 표시

**⑤ 지도**
- 운동 위치 표시 (핀 마커)
- "운동 위치" 라벨

### 상세 내용
- **메모 수정**: 이 화면에서 직접 메모 수정 가능
- **심박수 데이터**: HealthKit 연동으로 가져옴
- **운동 위치**: 운동 시작 시 자동으로 위치 기록

## 3. 메인화면 (요약)

| 항목 | 내용 |
|------|------|
| **탭** | 일지 |
| **타이틀** | "요약" + 오늘 날짜 (예: 3월 15일 일요일) |
| **역할** | 오늘의 운동 현황을 한눈에 보여주는 대시보드 |

### 구성 요소 (위→아래)

**① 오늘의 운동 카드**
- 원형 프로그레스 + 세트 수
- 운동 부위(예: 가슴), 총 세트 수 표시
- 클릭 → 5. 캘린더 페이지

**② 운동시간 / 세트수 카드** (2열)
- 운동시간: 오늘 총 운동 시간 (분)
- 세트수: 오늘 총 세트 수

**③ 세션 카드**
- 가장 최근 세션 요약 (부위, 칼로리, 요일)
- 클릭 → 2. 운동 결과 화면

**④ 운동 카드**
- "근력 강화 운동" 등 운동 타입 표시
- "운동 시작" 버튼
- 클릭 → 1. 카운트다운 → 운동중 화면 (바로 진입)

**⑤ 이번 주 세션 리스트**
- 이번 주 완료된 세션 목록 (부위, 요일, 시간, 세트수, 칼로리)
- "더보기 →" 클릭 → 4. 세션 목록 화면

**⑥ 하단 버튼**
- "요약 편집" — 메인화면 카드 내 표시 항목 커스터마이징
- "모든 카테고리 보기" — 추가할 수 있는 카드 종류를 보여주고 선택/추가

### 상세 내용
- **빈 상태(운동 안 한 날)**: 카드 레이아웃은 동일하게 유지, 데이터만 0 또는 비어있음으로 표시
- **요약 편집**: 각 카드 내 표시 항목을 커스터마이징하는 기능
- **모든 카테고리 보기**: 메인화면에 추가할 수 있는 카드 종류를 보여주고 선택/추가하는 기능

## 4. 세션 목록 화면 (전체 세션 히스토리)

| 항목 | 내용 |
|------|------|
| **진입 경로** | 메인화면 이번주 세션 "더보기" 클릭 |
| **네비게이션** | ← 뒤로가기, 타이틀 "세션" |

### 구성 요소

**① 필터 탭**
- 모두 | 가슴 | 등 | 하체 | 어깨 (부위별 필터)

**② 월별 그룹 세션 리스트**
- 월 단위로 그룹핑 (예: "2026년 3월")
- 각 세션 카드: 부위 아이콘 + 부위명 + 칼로리(KCAL) + 날짜/요일
- 클릭 → 2. 운동 결과 화면

### 상세 내용
- **데이터 범위**: 전체 세션 히스토리 (과거 포함)
- **스크롤**: 무한 스크롤로 과거 세션 계속 로드
- **필터**: 단일 선택 (한 번에 하나의 부위만 필터링)
- **삭제/편집**: 이 화면에서는 삭제 기능 없음

## 5. 캘린더 페이지

| 항목 | 내용 |
|------|------|
| **진입 경로** | 메인화면 오늘의 운동 카드 클릭 |
| **네비게이션** | ← 뒤로가기, 타이틀 "캘린더" |

### 구성 요소

**① 요일 헤더**
- 월 | 화 | 수 | 목 | 금 | 토 | 일

**② 월별 캘린더 (무한 스크롤)**
- 월 라벨 (예: "3월", "2월", "1월"...)
- 각 날짜마다 원형 프로그레스 링 (운동량 시각화)
- 운동한 날: 링 채워짐 (주황/골드)
- 운동 안 한 날: 빈 링 (어두운 톤)
- 오늘 날짜: 별도 강조
- 운동 세션이 있는 날: 초록 점(dot) 표시
- 클릭 → 2. 운동 결과 화면

### 상세 내용
- **세션 제한**: 하루 1세션 고정 — 날짜 클릭 시 바로 2. 운동 결과 화면으로 이동
- **프로그레스 링 기준**: 운동 여부만 (on/off), 운동량에 따른 차이 없음
- **스크롤**: 현재 월이 상단, 아래로 스크롤하면 과거 월로 이동 (무한 스크롤)

# Phase 3: 부가 기능

## 6. 운동 템포 페이지

| 항목 | 내용 |
|------|------|
| **탭** | 템포 |
| **타이틀** | "템포" / 부제: "수축·이완 타이밍에 집중하세요" |

### 구성 요소

**① 모드 토글**
- "수축 먼저" | "이완 먼저"

**② 상태 표시**
- 상태 텍스트 (대기 중 / 수축 / 이완 / 휴식)
- 원형 프로그레스 + 현재 세트 숫자
- 진행률: 현재 세트 / 총 세트

**③ 현재 상태 정보** (3열)
- 현재 세트 | 현재 횟수 | 구간

**④ 시간 설정** (2×2 그리드)
- 수축 시간 (초) — +/- 조절
- 이완 시간 (초) — +/- 조절
- 횟수 (회) — +/- 조절
- 세트 (세트) — +/- 조절

**⑤ 휴식 시간 설정**
- 휴식 시간 (초) — +/- 및 ±10 조절

**⑥ 시작 버튼**
- "시작" (accent 색상)

### 타이머 로직
- `async/await` + `Promise` 기반 1초 단위 동기화
- **경과 시간 기반 설계:** `Date.now()` 타임스탬프를 기준으로 계산하여 백그라운드 복귀 시 정확한 동기화 보장

### 오디오 피드백
- `expo-av`를 이용한 구간별 비프음(pip, pik) 및 숫자 음성 지원

### 백그라운드 처리

```
오디오 지속 재생
├─ expo-av: Audio.setAudioModeAsync({ staysActiveInBackground: true })
└─ app.json: "UIBackgroundModes": ["audio"]

타이머 동기화 (AppState 기반)
├─ 타이머 시작 시 → startedAt: Date.now() 를 Zustand에 저장
├─ 백그라운드 진입 → JS 스레드 suspend (타이머 정지)
├─ 포그라운드 복귀 → AppState 'active' 감지
│   └─ elapsed = Date.now() - startedAt
│   └─ syncProgressToElapsed(elapsed) 호출
│       → 현재 구간(수축/이완/휴식), 세트, 횟수 역산
│       → 프로그레스 바 + UI 즉시 동기화
└─ 결과: 유저는 화면 복귀 시 정확한 현재 상태를 확인
```

### 상세 내용
- **수축/이완 전환 알림**: 소리(비프음) + 진동(햅틱) 모두 사용
- **휴식 후 세트 전환**: 휴식 시간 끝나면 자동으로 다음 세트 시작
- **운동중 화면 연동**: 없음 — 독립 기능 (운동중 화면과 무관하게 단독 사용)
- **독립 타이머**: 운동중 화면(1-B)의 타이머와 별개로 템포 자체 타이머가 독립적으로 동작

## 7. 프로틴 페이지

| 항목 | 내용 |
|------|------|
| **탭** | 프로틴 |
| **타이틀** | "프로틴" / 부제: "가격 분석 · g당 최저가를 찾아보세요" |

### 구성 요소

**① 카테고리 필터**
- 전체 | WPC | WPI | Blend

**② 프로틴 제품 리스트**
- 각 카드: 제품명 + 가격 등급 뱃지(저점/중간/고점)
- 정보: 카테고리, 용량(g), 가격(원), g당 가격(원)
- 클릭 → 8. 프로틴 상세 페이지

### 데이터 아키텍처
- **데이터 원본:** 별도 크론 프로젝트에서 5분 주기로 프로틴 가격 추적 및 Supabase DB 갱신
- **앱 역할:** 읽기 전용(read-only) 클라이언트. `@supabase/supabase-js`로 직접 조회
- **보안:** Supabase RLS(Row Level Security) 활성화, `anon` 키에 `SELECT`만 허용

### 가격 뱃지 로직

최근 180일 가격 데이터를 기반으로 백분위(Percentile) 계산:

| 뱃지 | 조건 | 색상 |
|------|------|------|
| 저점 | 하위 20% 이하 | Green |
| 중간 | 평균 범위 | Blue |
| 고점 | 상위 20% 이상 | Red |

### 데이터 페칭 전략

```typescript
useQuery({
  queryKey: ['proteins', category, search],
  queryFn: fetchProteins,
  staleTime: 1000 * 60 * 5,
  gcTime: 1000 * 60 * 30,
  retry: 3,
  retryDelay: (attempt) => Math.min(1000 * 2 ** attempt, 10000),
});
```

### 상세 내용
- **정렬 기준**: 서버에서 결정 (클라이언트 관여 없음)
- **가격 데이터**: 서버에서 실시간 크롤링
- **가격 등급(저점/중간/고점)**: 서버에서 룰 정의 및 판정

## 8. 프로틴 상세 페이지

| 항목 | 내용 |
|------|------|
| **진입 경로** | 프로틴 페이지에서 제품 카드 클릭 |
| **네비게이션** | ← 뒤로가기, 타이틀 "상세 정보" |

### 구성 요소

**① 제품 헤더**
- 제품명 + 가격 등급 뱃지
- 용량 · 카테고리 · 맛

**② 특징 카드**
- 제품 특징 리스트 (예: "인지도가 높음", "맛과 성분은 좋지만 가격이 비싼편")

**③ 현재가 정보**
- 현재 가격 (원) + g당 가격

**④ 가격 추이 차트**
- 시간에 따른 가격 변동 라인 차트
- X축: 날짜 (예: 24-01 ~ 26-0x)
- Y축: 가격 (원)

**⑤ 구매 버튼**
- "구매하러 가기" — 외부 링크

### 상세 내용
- **구매 링크**: 외부 쇼핑몰 링크로 연결 (예: 쿠팡, 아이허브) — 서버에서 URL 제공
- **특징 카드 데이터**: 서버에서 제공 (크롤링 데이터 기반)
- **가격 추이 차트 기간**: 전체 기간 (서버에 데이터가 있는 만큼 모두 표시)
