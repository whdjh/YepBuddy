# 10. 운동 리마인더 알림

<aside>
⚙️

- **설계 원칙:** 알림은 서버 없이 로컬(`expo-notifications`)로 동작하며, 운동 종료 시점 기반으로 스케줄링된다.
- **트리거:** 마지막 운동 종료 시점(`completedAt`) 기준 22시간 경과 후 알림 발송.
- **전제 조건:** 한 번도 운동을 완료하지 않은 사용자에게는 알림을 발송하지 않는다.
- **야간 처리:** 앱에서 별도 야간 억제 없음. iOS 방해금지 모드에 위임한다.
- **설정:** 앱 내 별도 설정 화면 없음. iOS 설정에서만 알림 켜기/끄기를 제어한다.
</aside>

## 10.1. 알림 발송 플로우

1. **알림 예약**
    - 시스템은 운동 종료 시점(`completedAt`)을 기준으로 22시간 후에 알림을 예약한다.
    - 한 번도 운동을 완료하지 않은 사용자(`completedAt`이 없는 경우)에게는 알림을 예약하지 않는다.
2. **알림 액션 버튼**
    - 알림에는 두 개의 액션 버튼이 포함된다.
        - **"운동할게"**: 앱의 카운트다운 화면(1-A)으로 바로 진입하여 즉시 운동을 시작한다.
        - **"오늘은 쉴래"**: 해당 알림 시점 기준 22시간 후에 다음 알림을 재예약한다.
3. **알림 무시 시 동작**
    - 사용자가 알림에 아무 반응도 하지 않으면(버튼 미선택, 탭 안 함) 반복 알림 없이 대기한다.
    - 다음 알림은 사용자가 운동을 완료하거나 "오늘은 쉴래"를 선택할 때까지 발생하지 않는다.

## 10.2. 알림 취소 및 재설정

- 시스템은 사용자가 운동을 시작(카운트다운 진입)하면 예약된 알림을 즉시 취소한다.
- 시스템은 사용자가 운동을 종료하면 기존 알림을 취소하고, 새로운 22시간 타이머를 재설정한다.
- "오늘은 쉴래" 선택 후 22시간 내에 운동을 완료하면, "오늘은 쉴래"로 예약된 알림은 취소되고 운동 종료 기준으로 재설정된다.

## 10.3. 알림 메시지

1. **메시지 구성**
    - 타이틀: `YepBuddy`
    - 본문: `{고정 위트 메시지} 이번 주 {N}회 운동했어요.`
    - `{N}`은 이번 주(월~일) 완료된 세션 수를 반영한다.
    - 메시지는 항상 동일한 고정 문구를 사용한다.
    - *최종 메시지 문구는 추후 확정.*

## 10.4. 알림 퍼미션 플로우 (`expo-notifications`)

- 시스템은 앱 최초 실행 시 iOS 알림 권한을 요청한다.

```
트리거: 앱 최초 실행
├─ undetermined → requestPermissionsAsync() → iOS 시스템 팝업
├─ granted → 이후 운동 종료 시 알림 예약 가능
├─ denied → 알림 기능 비활성화 (별도 안내 없음)
└─ 이후 권한 변경 → iOS 설정에서만 제어
```

## 10.5. 엣지케이스

1. **첫 운동 전 사용자**
    - `completedAt`이 존재하지 않으면 알림 스케줄을 생성하지 않는다.
    - 첫 운동 종료 시점부터 알림 사이클이 시작된다.
2. **앱 삭제 후 재설치**
    - AsyncStorage가 초기화되므로 `completedAt`이 사라진다.
    - 첫 운동 전 사용자와 동일하게 처리한다 — 다음 운동 종료 시점부터 알림이 재개된다.
3. **기기 재부팅**
    - iOS 로컬 알림은 기기 재부팅 후에도 시스템이 자동 복원한다.
    - 별도 처리 불필요.
4. **"오늘은 쉴래" 연속 선택**
    - 매번 해당 시점 기준 22시간 후로 재예약된다.
    - 횟수 제한 없이 반복 가능하다.
5. **알림 권한이 거부된 상태에서 운동 종료**
    - 알림 예약이 실행되지 않는다.
    - 사용자가 iOS 설정에서 권한을 복원하면, 다음 운동 종료 시점부터 알림이 정상 동작한다.

## 10.6. 기술 구현

### 라이브러리

| 역할 | 라이브러리 |
|------|-----------|
| 로컬 알림 | `expo-notifications` |

### 상태 관리

```typescript
// Zustand 스토어 (기존 운동 스토어에 포함)
lastCompletedAt: string | null;   // 마지막 운동 종료 ISO timestamp
```

- `lastCompletedAt`은 Zustand + AsyncStorage에 저장한다.
- 알림 켜기/끄기는 iOS 설정에 위임하므로 앱 내 별도 상태 불필요.
