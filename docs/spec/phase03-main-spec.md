# 3. 메인화면 (요약)

<aside>
⚙️

- **탭:** 일지
- **역할:** 오늘의 운동 현황을 한눈에 보여주는 대시보드.
- **데이터 조회:** 앱 실행 시마다 HealthKit + AsyncStorage에서 새로 조회한다.
- **빈 상태:** 운동 안 한 날에도 카드 레이아웃은 동일하게 유지하며, 데이터만 0 또는 비어있음으로 표시한다.
</aside>

## 3.1. 화면 구성

### 타이틀

- "요약" + 오늘 날짜 (예: 3월 15일 일요일)

### ① 오늘의 운동 카드

- 원형 프로그레스 + 세트 수
- 운동 부위(예: 가슴 · 등), 총 세트 수 표시
- 운동 안 한 날: 프로그레스 0, 세트 수 0
- **클릭 →** 5. 캘린더 페이지

### ② 운동시간 / 세트수 카드 (2열)

- 운동시간: 오늘 총 운동 시간 (분) — HealthKit 조회
- 세트수: 오늘 총 세트 수 — AsyncStorage 조회 (부위별 세트수 총합)
- 운동 안 한 날: 0분 / 0세트

### ③ 세션 카드

- 가장 최근 세션 요약 (부위, 칼로리, 요일)
- 세션이 없는 경우 빈 상태로 표시
- **클릭 →** 2. 운동 결과 화면

### ④ 운동 카드

- "근력 강화 운동" 등 운동 타입 표시
- "운동 시작" 버튼
    - 심박수 디바이스 미연결 시 버튼 비활성화 (1.1 심박수 디바이스 체크 규칙 적용)
    - 당일 세션 완료 시 버튼 비활성화
- **클릭 →** 1. 카운트다운 → 운동중 화면 (바로 진입)

### ⑤ 이번 주 세션 리스트

- 이번 주(월~일) 완료된 세션 목록 (부위, 요일, 시간, 세트수, 칼로리)
- 세션이 없으면 빈 리스트 표시
- **"더보기 →" 클릭 →** 4. 세션 목록 화면

### ⑥ 하단 버튼

- **"요약 편집"** — 메인화면 카드 내 표시 항목 커스터마이징
- **"모든 카테고리 보기"** — 추가할 수 있는 카드 종류를 보여주고 선택/추가

## 3.2. 데이터 조회

<aside>
⚙️

앱 실행 시(메인화면 진입 시) HealthKit과 AsyncStorage에서 데이터를 병렬로 조회하여 화면을 구성한다.

</aside>

1. **HealthKit 조회**
    - 오늘의 운동 시간: 당일 `HKWorkout` 샘플의 `duration` 합산
    - 오늘의 칼로리: 당일 `HKWorkout` 샘플의 `totalEnergyBurned`
    - 이번 주 세션 목록: 이번 주(월~일) `HKWorkout` 샘플 조회
    - 가장 최근 세션: 가장 최근 `HKWorkout` 샘플 1건
2. **AsyncStorage 조회**
    - 오늘의 부위별 세트수: 당일 세션의 `bodyParts` 데이터
    - 이번 주 세션별 부위/세트수: 각 세션의 `bodyParts` 데이터
3. **데이터 매칭**
    - HealthKit의 `HKWorkout`과 AsyncStorage의 세션 데이터는 세션 ID(`startedAt` 기반)로 매칭한다.

## 3.3. 운동 시작 버튼 상태

- 시스템은 메인화면이 활성화된 동안 HealthKit에서 최근 5초 이내 심박수 데이터를 지속적으로 확인한다.
- 아래 두 조건을 모두 충족해야 운동 시작 버튼이 활성화된다.
    - 최근 5초 이내 심박수 데이터 존재 (디바이스 연결 상태)
    - 당일 완료된 세션 없음
- 조건 미충족 시 버튼 비활성화. 별도 안내 문구 없음.

## 3.4. 요약 편집 / 모든 카테고리 보기

- **요약 편집:** 각 카드 내 표시 항목을 커스터마이징하는 기능. 편집 설정은 AsyncStorage에 저장한다.
- **모든 카테고리 보기:** 메인화면에 추가할 수 있는 카드 종류를 보여주고 선택/추가하는 기능. 카드 구성 설정은 AsyncStorage에 저장한다.

## 3.5. 엣지케이스

1. **첫 사용자 (세션 0건)**
    - 모든 카드가 빈 상태/0으로 표시된다.
    - 운동 시작 버튼은 심박수 디바이스 연결 시 활성화된다.
2. **HealthKit 권한 거부 상태**
    - 운동 시간, 칼로리는 `--`로 표시한다.
    - 세트수, 부위 등 AsyncStorage 데이터는 정상 표시한다.
    - 운동 시작 버튼은 비활성화된다. (심박수 데이터 확인 불가)
