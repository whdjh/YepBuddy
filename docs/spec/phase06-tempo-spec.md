# 6. 운동 템포 페이지

<aside>
⚙️

- **탭:** 템포
- **역할:** 수축·이완 타이밍 가이드. 운동중 화면(1-B)과 완전 독립적으로 동작한다.
- **설정값 저장:** 저장하지 않는다. 매번 초기값으로 시작한다.
- **운동중 화면과의 관계:** 동시에 사용 가능하되, 각각 독립적으로 동작한다. 템포 타이머와 운동중 화면 타이머는 별개이다.
</aside>

## 6.1. 화면 구성

### 타이틀

- "템포" / 부제: "수축·이완 타이밍에 집중하세요"

### ① 모드 토글

- "수축 먼저" | "이완 먼저"

### ② 상태 표시

- 상태 텍스트 (대기 중 / 수축 / 이완 / 휴식)
- 원형 프로그레스 + 현재 세트 숫자
- 진행률: 현재 세트 / 총 세트

### ③ 현재 상태 정보 (3열)

- 현재 세트 | 현재 횟수 | 구간

### ④ 시간 설정 (2×2 그리드)

| 항목 | 조절 | 초기값 |
|------|------|--------|
| 수축 시간 (초) | +/- | *추후 확정* |
| 이완 시간 (초) | +/- | *추후 확정* |
| 횟수 (회) | +/- | *추후 확정* |
| 세트 (세트) | +/- | *추후 확정* |

### ⑤ 휴식 시간 설정

- 휴식 시간 (초) — +/- 및 ±10 조절

### ⑥ 시작 버튼

- "시작" (accent 색상)

## 6.2. 타이머 플로우

<aside>
⚙️

타이머는 `Date.now()` 타임스탬프 기반으로 설계하여 백그라운드 복귀 시 정확한 동기화를 보장한다.

</aside>

1. **시작 버튼 클릭**
    - 시스템은 `startedAt: Date.now()`를 저장하고 첫 번째 구간(수축 또는 이완)을 시작한다.
    - 시작 시 설정 UI는 비활성화된다.
2. **구간 진행 순서** (수축 먼저 모드 기준)
    - 수축 → 이완 → 수축 → 이완 → ... (횟수만큼 반복) → 휴식 → 다음 세트
    - 이완 먼저 모드: 이완 → 수축 순서로 변경
3. **구간 전환 시**
    - 비프음(pip, pik) + 햅틱 피드백을 발생시킨다. (`expo-av` + `expo-haptics`)
4. **휴식 종료 시**
    - 자동으로 다음 세트를 시작한다.
5. **모든 세트 완료 시**
    - 완료 사운드를 재생하고 "대기 중" 상태로 복귀한다.
    - 설정 UI가 다시 활성화된다.

## 6.3. 백그라운드 처리

<aside>
⚙️

오디오 지속 재생을 통해 백그라운드에서도 타이머가 동작하도록 보장한다.

</aside>

- **오디오 백그라운드 유지**
    - `expo-av`: `Audio.setAudioModeAsync({ staysActiveInBackground: true })`
    - `app.json`: `"UIBackgroundModes": ["audio"]`
- **포그라운드 복귀 시 동기화**
    - AppState `'active'` 감지 시 `elapsed = Date.now() - startedAt`으로 경과 시간을 계산한다.
    - 경과 시간을 기반으로 현재 구간(수축/이완/휴식), 세트, 횟수를 역산한다.
    - 프로그레스 바 + UI를 즉시 동기화한다.

## 6.4. 엣지케이스

1. **템포 진행 중 탭 전환**
    - 템포 타이머는 백그라운드에서 계속 동작한다. (오디오 지속 재생)
    - 다른 탭(일지/프로틴)으로 이동해도 타이머는 중단되지 않는다.
    - 템포 탭으로 복귀 시 현재 상태로 동기화된다.
2. **템포 진행 중 운동 시작/종료**
    - 템포와 운동중 화면은 완전 독립이므로 서로 영향 없음.
3. **앱 크래시 시**
    - 설정값을 저장하지 않으므로 복원하지 않는다. 초기값으로 시작한다.
