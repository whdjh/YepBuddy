# 5. 캘린더 페이지

<aside>
⚙️

- **진입 경로:** 메인화면 오늘의 운동 카드 클릭
- **데이터 소스:** HealthKit에서 `HKWorkout` 샘플 존재 여부로 운동 유무를 판단한다.
- **세션 제한:** 하루 1세션 고정. 운동한 날짜 클릭 시 바로 운동 결과 화면으로 이동한다.
</aside>

## 5.1. 화면 구성

### 네비게이션

- ← 뒤로가기
- 타이틀: "캘린더"

### ① 요일 헤더

- 월 | 화 | 수 | 목 | 금 | 토 | 일

### ② 월별 캘린더 (무한 스크롤)

- 월 라벨 (예: "3월", "2월", "1월"...)
- 현재 월이 상단, 아래로 스크롤하면 과거 월로 이동
- 각 날짜마다 원형 프로그레스 링으로 운동 여부를 시각화한다.
    - 운동한 날: 링 채워짐 (주황/골드) + 초록 점(dot)
    - 운동 안 한 날: 빈 링 (어두운 톤)
    - 오늘 날짜: 별도 강조
- 프로그레스 링 기준: 운동 여부만 (on/off). 운동량에 따른 차이 없음.

## 5.2. 날짜 클릭 동작

- **운동한 날짜 클릭 →** 2. 운동 결과 화면으로 이동
- **운동 안 한 날짜 클릭 →** 아무 동작 없음
- **미래 날짜 →** 아무 동작 없음

## 5.3. 데이터 조회

1. **초기 로드**
    - 화면 진입 시 현재 월의 `HKWorkout` 샘플을 조회하여 날짜별 운동 유무를 판단한다.
2. **무한 스크롤**
    - 아래로 스크롤하면 이전 월(한 달치) 데이터를 추가 로드한다.
    - HealthKit에 데이터가 없는 월이더라도 캘린더 그리드는 표시하며, 모든 날짜가 빈 링으로 표시된다.

## 5.4. 엣지케이스

1. **세션이 0건인 사용자**
    - 모든 날짜가 빈 링으로 표시된다. 어떤 날짜를 클릭해도 동작 없음.
2. **HealthKit 권한 거부 상태**
    - 운동 유무를 판단할 수 없으므로 모든 날짜가 빈 링으로 표시된다.
