# 2. 운동 결과 화면 (세션 상세)

<aside>
⚙️

- **진입 경로:** 운동 종료 후 자동 이동 / 세션 목록에서 세션 카드 클릭 / 캘린더 항목 클릭
- **데이터 소스:** HealthKit + AsyncStorage 혼합 방식
    - **HealthKit:** 운동 시간, 활동 칼로리, 총 칼로리, 심박수 데이터(차트용), 평균 심박수
    - **AsyncStorage:** 부위별 세트수, 메모, 위치
- **역할:** 조회 전용 화면. 세션 삭제는 불가하며, 메모만 수정 가능하다.
</aside>

## 2.1. 화면 구성

### 네비게이션

- ← 뒤로가기
- 타이틀: 날짜 (예: "3월 15일")

### ① 세션 헤더

- 부위 아이콘(들) + 부위명(들)
    - 다중 부위 선택 시 선택된 부위를 모두 표시한다. (예: "가슴 · 등")
    - 부위 미선택 시 "미지정"으로 표시한다.
- 날짜 + 총 운동 시간

### ② 메모

- 사용자가 운동중에 작성한 메모를 표시한다.
- 메모가 없는 경우 메모 영역을 빈 상태로 표시한다.
- **메모 수정:** 이 화면에서 직접 수정 가능하며, 수정 즉시 AsyncStorage에 저장한다.

### ③ 운동 세부사항 (2×2 그리드)

| 항목 | 데이터 소스 | 표시 형식 |
|------|-----------|----------|
| 운동 시간 | HealthKit | H:MM:SS |
| 활동 칼로리 | HealthKit | KCAL |
| 세트수 | AsyncStorage | 부위별 세트수의 총합 (예: 가슴 10 + 등 10 = 20세트) |
| 평균 심박수 | HealthKit | BPM |

### ④ 심박수 차트

- 시간 흐름에 따른 심박수 라인 차트를 표시한다.
- X축: 운동 시작 ~ 종료 시간 구간
- Y축: 심박수 (BPM)
- 평균 심박수 라인을 함께 표시한다.
- 심박수 데이터는 HealthKit에서 해당 운동 세션의 `startDate` ~ `endDate` 구간으로 조회한다.

### ⑤ 지도

- 운동 시작 시 기록된 위치를 정적 지도 + 핀 마커 1개로 표시한다. (`react-native-maps`)
- "운동 위치" 라벨을 함께 표시한다.
- 위치 데이터가 없는 경우(위치 권한 거부 등) 지도 영역을 표시하지 않는다.

## 2.2. 데이터 조회

1. **HealthKit 조회**
    - 시스템은 해당 세션의 `startDate`와 `endDate`를 기준으로 HealthKit에서 `HKWorkout` 객체를 조회한다.
    - `HKWorkout` 객체에서 운동 시간, 활동 칼로리, 총 칼로리를 읽어온다.
    - 심박수 차트용 데이터는 해당 운동 구간의 `HKQuantitySample`(heartRate)을 별도 쿼리로 조회한다.
    - 평균 심박수는 조회된 심박수 샘플의 평균값으로 계산한다.
2. **AsyncStorage 조회**
    - 시스템은 세션 ID를 키로 AsyncStorage에서 부위별 세트수, 메모, 위치 데이터를 읽어온다.
3. **세션 식별**
    - 각 세션은 운동 시작 시각(`startedAt`)을 기반으로 한 고유 ID로 식별한다.
    - HealthKit 조회와 AsyncStorage 조회를 동일한 세션 ID로 매칭한다.

## 2.3. 메모 수정

- 사용자는 메모 영역을 탭하여 수정 모드로 진입할 수 있다.
- 수정 내용은 즉시 AsyncStorage에 저장한다. (별도 저장 버튼 없음)
- 메모 수정은 AsyncStorage에만 반영되며, HealthKit 데이터에는 영향 없다.

## 2.4. 엣지케이스

1. **HealthKit 데이터가 없는 경우**
    - 앱 크래시 후 복원 등으로 HealthKit에 해당 세션의 Workout 데이터가 없을 수 있다.
    - 이 경우 운동 시간, 칼로리, 심박수는 `--`로 표시한다.
    - AsyncStorage 데이터(부위, 세트수, 메모)는 정상 표시한다.
2. **위치 데이터가 없는 경우**
    - 위치 권한 거부 또는 위치 기록 실패 시 지도 영역을 표시하지 않는다.
3. **부위 미선택 세션**
    - 부위를 선택하지 않은 세션은 헤더에 "미지정", 세트수는 0으로 표시한다.

## 2.5. 기술 구현

### 라이브러리

| 역할 | 라이브러리 |
|------|-----------|
| HealthKit 조회 | `react-native-health` |
| 심박수 차트 | `react-native-svg` (커스텀) 또는 차트 라이브러리 |
| 지도 | `react-native-maps` |
