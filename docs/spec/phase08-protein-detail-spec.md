# 8. 프로틴 상세 페이지

<aside>
⚙️

- **진입 경로:** 프로틴 페이지에서 제품 카드 클릭
- **데이터 소스:** Supabase에서 제품 상세 정보 및 가격 추이 데이터를 조회한다.
- **역할:** 개별 제품의 상세 정보, 가격 추이 차트, 외부 구매 링크를 제공한다.
</aside>

## 8.1. 화면 구성

### 네비게이션

- ← 뒤로가기
- 타이틀: "상세 정보"

### ① 제품 헤더

- 제품명 + 가격 등급 뱃지 (저점/중간/고점)
- 용량 · 카테고리 · 맛

### ② 특징 카드

- 제품 특징 리스트 (예: "인지도가 높음", "맛과 성분은 좋지만 가격이 비싼편")
- 서버에서 제공하는 크롤링 데이터 기반

### ③ 현재가 정보

- 현재 가격 (원) + g당 가격

### ④ 가격 추이 차트

- 시간에 따른 가격 변동 라인 차트
- X축: 날짜 (서버에 데이터가 있는 전체 기간)
- Y축: 가격 (원)

### ⑤ 구매 버튼

- "구매하러 가기" — 서버에서 제공하는 외부 쇼핑몰 URL로 연결 (예: 쿠팡, 아이허브)
- `expo-linking`으로 외부 브라우저에서 열기

## 8.2. 데이터 페칭

```typescript
useQuery({
  queryKey: ['protein', productId],
  queryFn: () => fetchProteinDetail(productId),
  staleTime: 1000 * 60 * 5,
  retry: 3,
  retryDelay: (attempt) => Math.min(1000 * 2 ** attempt, 10000),
});
```

- 제품 상세 정보와 가격 추이 데이터를 한 번에 조회한다.
- 가격 추이 차트 데이터는 전체 기간(서버에 데이터가 있는 만큼)을 모두 가져온다.

## 8.3. 엣지케이스

1. **네트워크 오류**
    - 3회 재시도 후에도 실패하면 에러 상태를 표시한다.
2. **구매 링크가 없는 제품**
    - 구매 버튼을 비활성화하거나 표시하지 않는다.
3. **가격 추이 데이터가 부족한 경우**
    - 데이터 포인트가 1개 이하인 경우 차트 대신 현재가만 표시한다.
