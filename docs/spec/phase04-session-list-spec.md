# 4. 세션 목록 화면 (전체 세션 히스토리)

<aside>
⚙️

- **진입 경로:** 메인화면 이번 주 세션 "더보기" 클릭
- **데이터 소스:** HealthKit + AsyncStorage 혼합 방식 (운동 결과 화면과 동일)
- **역할:** 전체 세션 히스토리를 월별로 그룹핑하여 조회. 삭제/편집 불가.
</aside>

## 4.1. 화면 구성

### 네비게이션

- ← 뒤로가기
- 타이틀: "세션"

### ① 필터 탭

- **모두 | 가슴 | 등 | 하체 | 어깨 | 팔 | 코어**
- 단일 선택 (한 번에 하나의 부위만 필터링)
- 기본값: "모두"
- **필터 매칭 규칙:** 세션에 선택된 부위가 하나라도 포함되면 표시한다.
    - 예: "가슴" 필터 시, "가슴+등" 세션도 표시됨

### ② 월별 그룹 세션 리스트

- 월 단위로 그룹핑하여 표시 (예: "2026년 3월")
- 각 세션 카드: 부위 아이콘(들) + 부위명(들) + 칼로리(KCAL) + 날짜/요일
- **클릭 →** 2. 운동 결과 화면

## 4.2. 데이터 조회

1. **초기 로드**
    - 화면 진입 시 현재 월의 세션 데이터를 조회한다.
    - HealthKit에서 현재 월의 `HKWorkout` 샘플을 조회하고, AsyncStorage에서 해당 세션들의 부위/세트수 데이터를 매칭한다.
2. **무한 스크롤**
    - 아래로 스크롤하면 이전 월(한 달치)을 추가 로드한다.
    - 더 이상 데이터가 없으면 로드를 중단한다.
3. **필터 적용**
    - 필터 변경 시 현재 로드된 데이터에서 클라이언트 사이드로 필터링한다.
    - 필터 상태에서 스크롤하여 추가 로드 시에도 동일한 필터가 적용된다.

## 4.3. 엣지케이스

1. **세션이 0건인 경우**
    - 빈 리스트를 표시한다. 별도 안내 메시지 없음.
2. **필터 결과가 0건인 경우**
    - 해당 필터에 맞는 세션이 없으면 빈 리스트를 표시한다.
3. **부위 미선택 세션**
    - "모두" 필터에서는 항상 표시된다.
    - 특정 부위 필터에서는 표시되지 않는다.
