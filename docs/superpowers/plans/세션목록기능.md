# 세션 목록 기능

> 전체 세션 히스토리를 월별로 그룹핑해서 보여주는 읽기 전용 화면.

## 개요
- 진입: 메인화면의 "이번 주 세션 더보기"
- 데이터 소스: HealthKit + AsyncStorage
- 정렬: 최신 → 과거
- 로드 방식: 현재 월부터 시작하는 무한 스크롤

## 화면 구성
- 네비게이션: 뒤로가기 + "세션"
- 필터 탭: 모두 / 가슴 / 등 / 하체 / 어깨 / 팔 / 코어
- 월별 그룹 리스트
- 각 세션 카드 클릭 시 결과 화면 이동

## 데이터 규칙
- 월 단위로 `HKWorkout` 조회
- 각 workout에 대응하는 AsyncStorage 메타를 병합
- 부위 필터는 로드된 데이터에 클라이언트 사이드 적용
- 부위 미선택 세션은 "모두"에서만 노출
