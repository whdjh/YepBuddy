# 결과 화면 기능

> 세션 상세 조회 전용 화면. 메모만 수정 가능하며 세션 삭제는 지원하지 않는다.

## 개요
- 진입: 운동 종료 후 자동 이동, 세션 목록 클릭, 캘린더 날짜 클릭
- 데이터 소스:
- HealthKit: 운동 시간, 활동 kcal, 총 kcal, 평균 심박수, 심박수 차트
- AsyncStorage: 부위별 세트수, 메모, 위치
- 세션 ID 규약: `sessionId = startedAt ISO string`

## 화면 구성
- 헤더: 부위 아이콘 / 부위명 / 날짜 / 총 운동 시간
- 메모: 조회 + 인라인 수정
- 운동 세부사항 2x2:
- 운동 시간
- 활동 칼로리
- 세트수 총합
- 평균 심박수
- 심박수 차트: 운동 구간의 heart rate series
- 위치 지도: 위치 데이터가 있을 때만 노출

## 데이터 조회 규칙
- HealthKit과 AsyncStorage를 같은 `sessionId`로 병합
- HKWorkout이 없으면 시간 / 칼로리 / 심박수는 `--` 처리
- AsyncStorage 데이터가 없으면 부위 / 메모 / 위치는 빈 상태 처리

## 메모 수정 규칙
- 결과 화면에서 메모만 수정 가능
- 수정 즉시 AsyncStorage 저장
- HealthKit 데이터는 수정하지 않음
