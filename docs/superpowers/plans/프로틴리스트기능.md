# 프로틴 리스트 기능

> 프로틴 제품 가격 분석과 g당 최저가 비교를 위한 읽기 전용 화면.

## 개요
- 진입: 프로틴 탭
- 데이터 원본: 별도 크론 프로젝트가 갱신하는 Supabase
- 앱 역할: 읽기 전용 클라이언트
- 보안: RLS 활성화, `anon` 키는 `SELECT`만 허용

## 공통 셋업
- `@supabase/supabase-js`
- `@tanstack/react-query`
- `react-native-url-polyfill`
- `_layout.tsx`에 `QueryClientProvider` 추가
- `shared/api/supabase.ts`에 공통 클라이언트 구성

## 화면 구성
- 타이틀 / 부제
- 카테고리 필터: 전체 / WPC / WPI / Blend
- 제품 카드 리스트
- 카드 정보: 제품명, 가격 등급, 카테고리, 용량, 가격, g당 가격
- 카드 클릭 시 상세 화면 이동

## 데이터 규칙
- 정렬과 가격 등급은 서버에서 결정
- 필터 변경 시 query key 변경으로 재조회
- 5분 staleTime, 30분 gcTime
- 네트워크 오류 시 재시도 후 에러 상태 표시
