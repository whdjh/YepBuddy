# 알림 기능

> 서버 없이 `expo-notifications` 기반 로컬 알림으로 운동 리마인더를 관리한다.

## 개요
- 트리거: 마지막 `completedAt + 22h`
- 첫 운동 전에는 알림 없음
- 앱 내 별도 설정 화면 없음
- 야간 억제는 iOS 방해금지에 위임

## 동작 플로우
- 운동 종료 시 기존 예약 취소 후 22시간 뒤 알림 예약
- 카운트다운 진입 시 예약 알림 즉시 취소
- 알림 액션:
- "운동할게" → 앱 열고 카운트다운 진입
- "오늘은 쉴래" → 현재 시각 기준 22시간 뒤 재예약
- 알림 무시 시 반복 예약 없음

## 메시지 규칙
- title: `YepBuddy`
- body: 고정 문구 + 이번 주 운동 횟수
- 이번 주 운동 횟수는 HealthKit 조회로 계산

## 권한 규칙
- 앱 최초 실행 시 권한 요청
- 거부되어도 운동 기능은 정상 동작
- 권한 복구 후 다음 운동 종료 시점부터 다시 예약 가능
