# 메인화면 기능

> 일지 탭 대시보드. HealthKit 측정값과 AsyncStorage 메타데이터를 병합해 오늘과 이번 주 운동 현황을 요약한다.

## 개요
- 진입: `src/app/(tabs)/index.tsx`
- 이동:
- 오늘의 운동 카드 → `/calendar`
- 세션 카드 → `/workout/[sessionId]`
- 운동 카드 → `/workout/countdown`
- 이번 주 세션 더보기 → `/sessions`

## 데이터 병합 전략
- 오늘의 운동 카드: HK workout 존재 여부 + bodyParts / setCount
- 운동시간 카드: 당일 `HKWorkout.duration` 합산
- 세트수 카드: 당일 세션 `bodyParts[].setCount` 총합
- 세션 카드: 최근 workout 1건 + 대응 메타
- 이번 주 세션 리스트: 월~일 workouts + 대응 메타

## 운동 시작 규칙
- `enabled = !hasTodayCompletedSession`
- 심박수 디바이스 연결 여부는 시작 조건에 포함하지 않음
- 당일 완료 세션만 체크해서 버튼 활성 / 비활성 결정

## 화면 구성
- 타이틀: "요약" + 오늘 날짜
- 오늘의 운동 카드
- 운동시간 / 세트수 카드
- 최근 세션 카드
- 운동 카드
- 이번 주 세션 리스트
- 하단 편집 액션

## 빈 상태 / 오류 상태
- 운동 안 한 날에도 카드 레이아웃은 유지
- HealthKit 권한이 없어도 운동 시작은 가능
- HK 측정값만 `0` 또는 `--` 처리
- AsyncStorage 기반 메타는 있으면 그대로 노출
