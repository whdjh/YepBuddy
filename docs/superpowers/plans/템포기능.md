# 템포 기능(완료)

> 수축·이완 타이밍 가이드. 운동중 화면과 독립적으로 동작하며 설정값은 저장하지 않는다.

## 개요
- 운동중 화면과 상태 공유 없음
- `Date.now()` 기반으로 현재 구간 역산
- 사운드 + 햅틱으로 전환 피드백
- 백그라운드에서도 정확한 동기화 유지

## 확정 초기값
| 항목 | 값 |
|------|----|
| 수축 시간 | 3초 |
| 이완 시간 | 3초 |
| 횟수 | 10회 |
| 세트 | 3세트 |
| 휴식 | 60초 |
| 준비 카운트다운 | 30초 |

## 구현 상태
- `tempoReducer`, `tempoCalculator`, `useTempoTimer`, `tempoSound` 구현 완료
- `TempoScreen`, `TempoRingDisplay`, `TempoSettings`, `TempoModeButtons` 구현 완료

## 핵심 규칙
- 설정값은 비저장
- 모든 구간은 경과 시간 기반으로 계산
- 마지막 세트 완료 시 `idle` 복귀
- 앱 크래시 시 복원하지 않음
