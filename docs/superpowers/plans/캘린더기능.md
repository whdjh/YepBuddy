# 캘린더 기능

> 월별 캘린더와 무한 스크롤. 운동한 날짜를 시각화하고 클릭 시 결과 화면으로 이동한다.

## 개요
- 진입: 메인화면 오늘의 운동 카드
- 데이터 소스: HealthKit workout 존재 여부
- 시각화 기준: 운동 여부만 on/off
- 전제: 하루 1세션 기준으로 날짜 → sessionId 1:1 매핑

## 화면 구성
- 네비게이션: 뒤로가기 + "캘린더"
- 요일 헤더
- 월별 캘린더 그리드
- 운동한 날: 링 채움 + 점 표시
- 운동 안 한 날: 빈 링
- 미래 날짜: 비활성

## 동작 규칙
- 운동한 날짜 클릭 → 결과 화면 이동
- 운동 안 한 날짜 클릭 → 아무 동작 없음
- 미래 날짜 클릭 → 아무 동작 없음

## 데이터 규칙
- 월 단위 `HKWorkout` 조회
- `YYYY-MM-DD` 키로 workout 날짜 집합 생성
- `sessionIdByDate`에 `startedAt ISO` 보관
- HK 권한이 없으면 모든 날짜를 빈 상태로 표시
